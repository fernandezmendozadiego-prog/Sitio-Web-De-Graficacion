# Instrucciones
Para que funcione este codigo aqui se pondra una guia de como hacer que funcione, para esto se necesita unos requisitos previos para que funcione el sitio y sea visible
## Requsitos
Tener Phoenix Code Instalado

Tener WINRAR instalado
## Pasos
1.Descargar el archivo dando click en el boton verde code

2.Abrir el archivo con WINRAR y descomprimir el archivo en carpeta y guardarlo en carpeta en descargas
<img src="./imagenes/Screenshot 2026-10-13 130024.png" alt="Captura de pantalla" width="600">

3.Abrir Phoenix code y abrir la carpeta descomprimida 

4.Abrir la carpeta en phoenix code que se ubica en descargas
<img src="./imagenes/Screenshot 2026-10-13 130024.png" alt="Captura de pantalla" width="600">

5.Hacer click en la carpeta index y luego en la prevista de la ventana
<img src="./imagenes/Screenshot 2026-10-13 130024.png" alt="Captura de pantalla" width="600">

6.Poner la ventana en modo prevista y abrirlo en el explorador del deseo haciendo click en la parte derecha del titulo del archivo
