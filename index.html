Sección informativa

En Khan Academy dibujamos usando ProcessingJS dentro de un simulador. Para llevar esos dibujos a una página web real necesitamos entender dos cosas: la etiqueta HTML <canvas> y la librería p5.js.

1. La etiqueta HTML <canvas>

La etiqueta <canvas> (lienzo) es un elemento de HTML5 que crea un área rectangular en la página donde se puede dibujar con JavaScript, píxel por píxel. Por sí sola es solo un rectángulo vacío y transparente; todo el dibujo se hace desde código.

<canvas id="miCanvas" width="400" height="300">
  Tu navegador no soporta canvas.
</canvas>
  • width y height definen el tamaño real en píxeles (por defecto 300 × 150).
  • El texto dentro de la etiqueta solo aparece si el navegador no soporta canvas.
  • El sistema de coordenadas empieza en la esquina superior izquierda (0, 0): la x crece hacia la derecha y la y crece hacia abajo, igual que en Khan Academy.

Contexto de renderizado 2D

Para dibujar hay que pedirle al canvas un contexto de renderizado, que es el objeto que contiene todas las funciones de dibujo. Para gráficos planos se usa el contexto "2d" (también existen "webgl" y "webgl2" para 3D).

const canvas = document.getElementById("miCanvas");
const ctx = canvas.getContext("2d");   // obtenemos el contexto 2D

ctx.fillStyle = "skyblue";             // color de relleno
ctx.fillRect(0, 0, 400, 300);          // rectángulo de fondo

ctx.beginPath();                       // iniciamos una figura
ctx.arc(200, 150, 60, 0, Math.PI * 2); // círculo: x, y, radio, ángulo inicio, ángulo fin
ctx.fillStyle = "gold";
ctx.fill();                            // rellenamos
ctx.lineWidth = 4;
ctx.strokeStyle = "orange";
ctx.stroke();                          // dibujamos el borde

ctx.font = "20px Arial";
ctx.fillStyle = "black";
ctx.fillText("Hola canvas", 140, 260); // texto

Resultado de ese código (dibujado con canvas nativo, sin librerías):

Tu navegador no soporta canvas.

¿Cómo se anima con canvas nativo?

Se usa requestAnimationFrame(), que llama a una función unas 60 veces por segundo. En cada llamada se borra el canvas y se dibuja todo de nuevo en su nueva posición.

let x = 0;
function animar() {
  ctx.clearRect(0, 0, canvas.width, canvas.height);
  ctx.fillRect(x, 100, 50, 50);
  x = x + 2;
  requestAnimationFrame(animar);
}
animar();

2. Fundamentos de la librería p5.js

p5.js es una librería de JavaScript gratuita y de código abierto, basada en Processing, creada para hacer dibujo, animación e interacción de forma sencilla. Por dentro usa el mismo <canvas> y su contexto 2D, pero nos da funciones mucho más cortas. Por eso es casi idéntica a lo que usamos en Khan Academy.

Cómo se agrega a una página

<script src="https://cdnjs.cloudflare.com/ajax/libs/p5.js/1.9.4/p5.min.js"></script>
<script src="js/mi-dibujo.js"></script>

Estructura básica: setup() y draw()

function setup() {
  // Se ejecuta UNA sola vez al inicio
  createCanvas(400, 400);   // crea el <canvas> automáticamente
}

function draw() {
  // Se repite unas 60 veces por segundo (animación)
  background(220);
  fill(255, 0, 0);
  ellipse(mouseX, mouseY, 50, 50);  // círculo que sigue al mouse
}

Modo global y modo instancia

El ejemplo anterior usa el modo global: las funciones de p5 quedan sueltas y solo cabe un dibujo por página. En este sitio usamos el modo instancia: cada dibujo es una función que recibe un objeto p y todas las funciones de p5 se escriben con p. al inicio. Así cada dibujo queda ordenado en su propio archivo y se puede colocar dentro del elemento HTML que nosotros elijamos.

const miDibujo = function (p) {
  p.setup = function () {
    p.createCanvas(400, 400);
  };
  p.draw = function () {
    p.background(220);
    p.ellipse(p.mouseX, p.mouseY, 50, 50);
  };
};

// Crea el dibujo dentro del elemento con id="lienzo"
new p5(miDibujo, "lienzo");

Interactividad

  • mouseX, mouseY: posición actual del mouse.
  • mouseIsPressed: true mientras se mantiene presionado.
  • mousePressed(), mouseClicked(), keyPressed(): se ejecutan con cada clic o tecla.
  • frameCount: número de cuadros dibujados, útil para animar.
  • createSlider(), createButton(): crean controles HTML desde p5.

Animación en p5.js

Una animación es una serie de dibujos que cambian un poquito en cada cuadro. Como draw() se repite unas 60 veces por segundo, basta con seguir tres pasos:

  1. Declarar variables fuera de draw() para guardar la posición o el tamaño. Si se declararan dentro, volverían a su valor inicial en cada cuadro y nada se movería.
  2. Dibujar usando esas variables en lugar de números fijos.
  3. Cambiar las variables al final de draw() (sumar o restar), para que el siguiente cuadro se dibuje un poco distinto.

Además, background() al inicio de draw() borra el cuadro anterior. Sin él, cada figura dejaría un rastro sobre el lienzo.

Los ejemplos muestran el código base de Khan Academy. En el sitio, estos dibujos tienen detalles extra (degradados, estelas, arcoíris…), pero la animación principal funciona exactamente igual.

Ejemplo 1: crecer (El sol que explota)

El sol crece porque su tamaño aumenta 1 píxel en cada cuadro. El pasto se dibuja después del sol, y por eso tapa su mitad de abajo: en el canvas, lo último que se dibuja queda encima.

let sunSize = 30;                  // 1. variable fuera de draw()

function draw() {
  background(82, 222, 240);        // borra el cuadro anterior
  fill(255, 204, 0);
  ellipse(200, 298, sunSize, sunSize); // 2. se dibuja con la variable
  fill(76, 168, 67);
  rect(0, 300, 400, 100);          // el pasto tapa la mitad del sol
  sunSize = sunSize + 1;           // 3. cambia para el siguiente cuadro
}

Ejemplo 2: varias variables y posiciones relativas (Nubes que se separan)

Cada nube está hecha de tres elipses que dependen de una sola variable (leftX o rightX). Al cambiar esa variable, la nube completa se mueve junta. Una nube resta (-=) y la otra suma (+=), así que se alejan entre sí mientras el sol crece.

ellipse(leftX, 150, 126, 97);       // centro de la nube
ellipse(leftX + 62, 150, 70, 60);   // lado derecho
ellipse(leftX - 62, 150, 70, 60);   // lado izquierdo

leftX -= 1;      // la nube izquierda va a la izquierda
rightX += 1;     // la nube derecha va a la derecha
sunRadius += 2;  // el sol crece

Ejemplo 3: movimiento en diagonal (Estrella fugaz)

Si en cada cuadro se cambia x y también y, la figura se mueve en diagonal. La velocidad depende de cuánto se suma: la primera estrella avanza 3 a la derecha y 1 hacia abajo; la segunda avanza 2 a la izquierda y 2 hacia abajo, así que baja más inclinada.

xpos = xpos + 3;     // derecha
ypos = ypos + 1;     // abajo (despacio)
ellipse(xpos, ypos, 10, 10);

xpos2 = xpos2 - 2;   // izquierda
ypos2 = ypos2 + 2;   // abajo (más rápido)
ellipse(xpos2, ypos2, 10, 10);

Ventajas de p5.js frente al canvas nativo

  • Código más corto: ellipse(200, 200, 50, 50) en lugar de 4 líneas con beginPath y arc.
  • El ciclo de animación (draw) ya viene incluido.
  • Variables del mouse y teclado listas para usar.
  • Muy parecido a Processing, que es lo que aprendimos en Khan Academy.
